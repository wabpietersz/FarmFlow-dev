# Archive

Earlier planning documents, kept for history. They describe intentions at the time and
**are not current**: the [functional spec](../FarmFlow-Target-Functional-Spec.md) and the
[build roadmap](../FarmFlow-Build-Roadmap.md) replace them, and the code is the final word.

- `original-plans/` — the first requirements (FRD), the 24-week implementation plan and its task tracker, and the original architecture and technical design.
- `module-plans/` — per-module improvement plans (feed, inventory, treasury, finance, sales, payroll, navigation, UI audit) that were folded into the roadmap phases.
- `deployment/` — the earlier production deployment write-up and the Render.com blueprint (no longer used; see the [deployment guide](../Deployment-Guide.md)).
