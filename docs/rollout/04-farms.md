# Session 2: Farms and batches

**With:** a farm manager, and a supervisor if they keep the daily book.
**Time:** 90 minutes, then a week of daily entry on the phone.
**Guide:** [../user-guide/02-farms.md](../user-guide/02-farms.md)
**Before:** farms and houses exist; vaccine in the farm's store (Session 1a); feed available from the mill (Session 1b); a vaccination programme and growth curve in **Settings → Health & growth**.

## Ask first: how it's done today

- What is written down each day, by whom, at what time, and where?
- How are deaths counted and what causes do you record?
- How is feed use measured: bags opened, or weighed?
- How often are birds weighed, and how many?
- Who decides and records vaccinations? What happens when one is missed?
- What happens between batches (cleaning, rest days)?
- When do you know whether a batch made money?

## Scripted steps

| ID | Step | Expected | ✓ |
|---|---|---|---|
| F-1 | **Farms → Batches → New batch**: farm, house, number of chicks, placement date about 25 days ago. | Batch created; health tasks appear from the programme, dated from placement | |
| F-2 | Record the **Chick Placement** (quantity, dead on arrival, cost). | Live birds = placed − DOA; chick cost shows in the batch's costs | |
| F-3 | Open the batch → **Today's check** on a phone. Enter deaths with a cause, feed, water, weight, temperature. | Saved; live birds drop; actual weight shows against the target curve | |
| F-4 | Put the phone in aeroplane mode. Do another day's check. Turn signal back on. | The entry waits, shown in the offline banner, then syncs by itself | |
| F-5 | Edit yesterday's record. | Change saved; live birds recalculated | |
| F-6 | **Farms → Health & houses → Due now**: mark a vaccination **Done**. | Recorded; vaccine stock drops from the farm's own store first; cost added to the batch | |
| F-7 | **Skip** another task with a reason. | Marked skipped; reason kept | |
| F-8 | **Vet visits**: record a visit with findings, treatment and cost. | Listed; cost reaches the batch | |
| F-9 | Change the batch's placement date by a day. | Health tasks move with it | |
| F-10 | Home → **To do**. | Shows overdue health tasks and any day with no daily log | |
| F-11 | Batch → **Performance & profit**. | Cost lines for chicks, feed, medicine, labour, shared costs; "where the cost came from" for each | |
| F-12 | **Farms → Farm control → site consumption**: record a farm-level use or cost. | Reaches batches on that farm in proportion to bird-days | |
| F-13 | After the batch is sold (Session 3), **Close this batch**. | If birds don't add up (placed − deaths − sold ≠ 0) it says so and asks to record the difference; once closed the numbers are frozen | |
| F-14 | **Health & houses → Houses.** | A turnaround checklist has started for that house | |
| F-15 | **Batches → history**. | The closed batch is listed with FCR, EPEF, cost per kg and profit, best values marked | |

## Should be refused

| ID | Try | Expected |
|---|---|---|
| F-R1 | Place a second batch in a house that already has one | Refused |
| F-R2 | Record more deaths than there are live birds | Refused |
| F-R3 | Edit a daily record on a closed batch | Refused |
| F-R4 | A Farm A manager opens a Farm B batch | Refused |
| F-R5 | A daily record dated before placement | Refused |

## Free-use week

The farm manager does **Today's check** every day for one real house, using the real numbers with the test batch. On at least one day, do it where the signal is worst.

## Feedback to draw out

- Is Today's check quicker or slower than the book? What did you still write on paper?
- Is one batch = one house right for you, or do you split a delivery of chicks across houses and think of it as one flock?
- Are the mortality causes the ones you use?
- Do you weigh birds daily, weekly, or only before catching?
- Is the vaccination list something you'd trust instead of the wall chart?
- Does the cost so far look believable? Which line surprised you?
- Did offline work where you actually stand when you do the check?
- Is "house" the word you use? "Cage"? "Shed"? (Some screens still say "cage".)

## Passed when

A week of daily checks has been entered on a phone by the manager, including one offline, and they can read the batch's cost and say which lines they believe.
